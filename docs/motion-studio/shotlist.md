# Shotlist

Jeder Beat: Eintritt → Austritt → Zweck. Ein durchgehendes Objekt (die Suchkarte bzw.
die Profilkarte) bleibt über alle Beats erkennbar dasselbe.

## Film A – Brands (16 s)

| Zeit | Beat | Bild | Zweck |
|---|---|---|---|
| 0,0–2,0 | HOOK | Leere Suchkarte „Wofür suchst du Creator?“, Cursor tippt: „Skincare-Serum, Reel für Instagram, Frau 25–35“ | Sofort das Produkt in Aktion statt Logo |
| 2,0–3,0 | KLICK | Cursor auf „Creator suchen“, Button drückt, Lupe dreht kurz | Die eine Handlung |
| 3,0–6,0 | ERGEBNISSE | Suchkarte schrumpft nach oben, 4 Creator-Karten federn nacheinander ein (Initialen-Avatar, Name, Stadt, Themen, „Per E-Mail erreichbar“) | Beweis: echte Profile, passend |
| 6,0–8,5 | AUSWAHL | Cursor klickt bei 2 Karten „+ Zur Auswahl“ → „✓ In deiner Auswahl“ (grün), Auswahl-Leiste fährt unten ein: „2 Creator in deiner Auswahl“ | Bewusste Auswahl statt Algorithmus |
| 8,5–11,0 | ANFRAGE | Klick „Kostenlos Anfrage senden“, Formular-Panel (Name, E-Mail, Projekt) füllt sich in 3 Zügen | Kein Login, kein Abo |
| 11,0–13,5 | MAIL | Panel wird zur Mail: „Deine Creator-Auswahl ist da“ mit 2 Kontaktzeilen, Häkchen | Ergebnis: direkte Kontakte |
| 13,5–16,0 | CLOSE | Headline „Kostenlos. Ohne Provision.“ + Wortmarke + „ugc-vz.de“ (nur Video; Website-Loop springt zu 0) | Merksatz + CTA |

## Film B – Creator (16 s)

| Zeit | Beat | Bild | Zweck |
|---|---|---|---|
| 0,0–2,5 | HOOK | Handy-Mockup, Formular „Als Creator anmelden“: Name, Themen-Chips (Beauty, Food) werden angetippt, Social-Link | Anmeldung ist schnell |
| 2,5–4,5 | SENDEN | „Profil anlegen“ gedrückt → Mail-Benachrichtigung „Bestätige dein kostenloses UGC-VZ-Profil“ rutscht oben ins Bild | Einmal bestätigen |
| 4,5–6,5 | BESTÄTIGEN | Tipp auf Bestätigen-Button in der Mail, Häkchen, Toast „Dein Creator-Profil ist aktiv“ | Double-Opt-in = echt |
| 6,5–9,5 | LIVE | Handy dreht leicht weg, Profilkarte erscheint im Verzeichnis-Raster zwischen anderen (gedimmt), Badge „Live“ | Sichtbar für Brands |
| 9,5–13,0 | ANFRAGE | Push: „Neue Brand-Anfrage – Eine Brand interessiert sich für dein Profil“, Mail öffnet: Projekt, Budget-Zeile, „Antworten“ | Der Payoff |
| 13,0–16,0 | CLOSE | „Kostenlos. Ohne Provision. Direkt mit der Brand.“ + Wortmarke + „ugc-vz.de/creator“ | Merksatz + CTA |

## Formate

- **16:9:** Suchkarte links, Ergebnisse als 4er-Raster; Kamera bleibt weit.
- **9:16:** eine Spalte, 2 Karten statt 4, Schrift +25 %, Auswahl-Leiste als Bottom-Sheet.
- **Website:** 16:9-Komposition responsiv; Tabs „Für Brands / Für Creator“, startet beim
  Sichtbarwerden, Pause-Button, Fortschrittsbalken mit den Beat-Namen als Sprungmarken.

## Prüfung vor Export (Kontaktbogen)

1 Frame pro Beat + Streifen um die schnellsten Übergänge. Checkliste: lesbar auf Handy,
Safe Area, nur echte UI, Typo/Farbe konsistent, keine hässlichen Zwischenframes,
starke erste 2 s, letzter Frame taugt als Poster. Danach 3 größte Fehler beheben.
